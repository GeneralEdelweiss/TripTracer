# Komponenten

Hier wird der letzte V0.3-Bauteilstand importiert:
- `v0.3/Bauteilliste.csv`: referenzierte Bauteile aus dem Schaltplan.
- `v0.3/Pad-Netze.csv`: Pad- und Netzdaten.
- `v0.3/Validierung.json`, `v0.3/Pruefbericht.json`: **nur strukturelle** Prüfungen.
- `components.csv`: abgeleiteter Bauteilkatalog mit Prüfstatus.
- `library_inventory.csv`: Dateiinventar mit SHA-256.

Ein grüner Strukturcheck bedeutet **nicht** einen bestandenen ERC oder eine geprüfte Schaltung.
