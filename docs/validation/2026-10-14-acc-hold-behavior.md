# ACC/HOLD behavioral test contract (2026-10-14)

Executable specification: `python3 tools/test_acc_hold_state_machine.py`.

**Status:** Logical reference model committed, **not** KiCad wiring, SPICE, native ERC, hardware qualification or an executed CI test report. The 30,000 ms time value is **only a test fixture**. It does not set the required shutdown interval; actual allowable duration depends on worst-case SD flush and component tolerances.

The Python model implements:
- ACC asserted -> vehicle main-enable high, independent of MCU_HOLD or 5V_BUCK_RAW (cold bootstrap).
- Falling *qualified* ACC edge -> one finite deadline.
- After ACC falling edge -> enable iff MCU_HOLD_REQ and vehicle-derived raw 5V are present and deadline is not expired.
- After deadline -> no retrigger while ACC remains low, even for MCU_HOLD stuck high.
- A new ACC-high state clears the deadline; a later qualified falling edge may arm again.
- USB-only is not a vehicle-rail qualifier.

**Important distinction:** The input `acc` represents *debounced, validated ACC*, **not raw M8 pin level**. Real ACC glitches could re-arm the model and therefore require an analog/digital qualifier whose thresholds, delay and safety impact are explicitly verified. `vehicle_5v` means 5V generated by the vehicle buck before any USB mux. A real controller needs brownout-safe hardware state keeping the deadline/non-retrigger property for the entire allowed interval. The simple reference model cannot show what happens when its own power disappears.

The model does not solve the essential chicken-and-egg question: a timer supplied from vehicle 5V cannot maintain that 5V until the ACC falling event has already generated a finite hold window and correctly gated the MAIN_ENABLE net. Source switching, ramp-up, power loss, tolerance and latches need circuit-level proof.

**Next engineering gate:** develop a concrete low-leakage power-independent ACC edge qualification, non-retriggerable pulse, and hardware re-arm interlock; compare complete TLC555-Q1 and LTC6993-3 implementations including their external logic before KiCad integration. The raw 5V qualification must never be back-fed from USB. Preserve LM74930-Q1 protection and LMR36520 buck choice. No fabrication sign-off.
